## How to run

- Python dependencies: cobra, pandas, numpy, matplotlib, jupyterlab, ipykernel.
- `python -m pip install cobra pandas numpy matplotlib jupyterlab ipykernel`
- Open `assignment2.ipynb` in PyCharm or Jupyter, with the model and expression data in the same folder.
- Run `assignment2.ipynb` top to bottom (give run all).
